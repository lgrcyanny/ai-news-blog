### 🔍 重点论文深度解析

#### 1. DelTA — 判别式 Token 信用分配：RLVR 进入「精细化工」时代
- **核心问题**: RLVR 中 reward 是序列级别的，无法区分哪些 token 真正贡献了正确推理，导致信用分配粗糙、训练效率低
- **方法**: 将 reward 分解为 token 级别的判别式信用信号，训练一个辅助判别器来评估每个 token 对最终结果的贡献，实现细粒度 RL 信号
- **价值**: 如果 token 级信用分配可行，RLVR 训练效率将大幅提升，并为「模型在哪一步想错了」提供可解释性

#### 2. Full Attention Strikes Back — 完整 Attention 百步蒸馏到稀疏架构
- **核心问题**: 稀疏 Attention 效率高但精度损失大，完整 Attention 精度好但推理成本高——能否鱼与熊掌兼得？
- **方法**: 提出一种新的迁移蒸馏方法，在仅 100 个训练步内将完整 Attention 的能力迁移到稀疏 Attention 架构，保持 99%+ 精度
- **价值**: 意味着可以「用稀疏架构推理，却享受完整 Attention 的精度」，可能成为 LLM 推理优化的标准技术路径

#### 3. π-Bench — 主动式 Agent 评测：从「问答」到「助理」
- **核心问题**: 现有 Agent 评测（WebArena、SWE-bench）是被动响应式，真实场景中用户期望 Agent 主动管理日程、追踪任务、协调沟通
- **方法**: 构建长周期工作流评测，覆盖日程安排、邮件处理、文档协作、多任务追踪等 12 类主动助理场景，Agent 需自主决定何时行动
- **价值**: 填补了「主动式 Agent」评测空白，对于构建真正的 AI 个人助理具有方向性指导意义
