### 🔍 重点论文深度解析（3 篇，每篇 3-4 行）

#### 1. When Tools Fail — Agent 工具失效动态恢复
- **核心问题**: 现有 Agent 评测假设工具调用总是成功，真实场景中 API 超时、参数错误、工具不可用是常态
- **方法**: 构建含工具异常注入的动态重规划评测基准，涵盖恢复策略选择、替代工具发现、任务降级执行等多维度
- **价值**: 首次将 Agent 鲁棒性评测从"理想环境"推入"故障环境"，为生产级 Agent 部署提供关键质量指标

#### 2. OpenSkill — 开放世界 Agent 自进化
- **核心问题**: 人工定义 Agent skill 无法覆盖开放世界的长尾场景，需要 Agent 自主发现和学习新能力
- **方法**: 基于交互式环境探索 + 成功经验提炼，Agent 自动识别可复用行为模式并封装为技能，支持持续增量学习
- **价值**: 将 Agent 能力边界从"人类预设"推向"环境驱动"，是通往通用 Agent 的关键技术路径

#### 3. Thinking with Imagination — 世界模拟器中的 Agent 视觉推理
- **核心问题**: 多模态模型擅长静态图像理解，但缺乏在动态 3D 空间中"想象"物体关系和动作后果的能力
- **方法**: 将世界模拟器作为 Agent 的交互式推理环境，Agent 在模拟器中生成假设场景并观察结果来验证空间推理
- **价值**: 打通了视觉推理→世界模拟→具身决策的技术链路，对机器人和 AR 应用有直接价值
