### 🔍 重点论文深度解析

#### 1. OPD-Evolver — 在线策略蒸馏进化
- **核心问题**: Agent 能力提升依赖人工设计 reward/prompt，缺乏自主进化机制
- **方法**: 通过 On-Policy Distillation 从多任务中蒸馏通用 Agent 进化策略，实现无需人工干预的持续自我改进
- **价值**: 通往自主进化 Agent 的关键一步，减少人工调优成本

#### 2. ACE-Ego-0 — 统一自我中心人机数据
- **核心问题**: 人类操作数据与机器人数据格式不统一，无法联合训练 VLA 模型
- **方法**: 统一自我中心视觉-语言-动作表示，首次实现人机数据联合预训练
- **价值**: 破解机器人数据稀缺瓶颈，大幅降低 VLA 预训练数据获取成本

#### 3. GameCraft-Bench — 真实游戏引擎 Agent 评测
- **核心问题**: 现有代码 Agent 评测停留在单文件生成，无法评估端到端复杂工程能力
- **方法**: 在真实游戏引擎中要求 Agent 从零构建可玩游戏，涉及代码生成、资源管理、玩法设计
- **价值**: 推动 Agent 从「写代码片段」向「完成完整工程」演进
