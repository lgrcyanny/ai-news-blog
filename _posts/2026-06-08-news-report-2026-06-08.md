### 🔍 重点论文深度解析（3 篇）

#### 1. AdaPlanBench — LLM Agent 自适应规划评测
- **核心问题**: 现有 Agent 规划评测假设静态世界，真实场景中环境和用户约束持续变化
- **方法**: 构建含世界状态漂移、用户偏好变更、资源约束动态调整的规划基准
- **价值**: 填补 Agent 动态重规划评测空白，推动从"一次性规划"到"持续适应"

#### 2. RobotValues — 家庭机器人价值观冲突评测
- **核心问题**: 家用机器人面临隐私、安全、自主权等多重价值观冲突时如何决策
- **方法**: 构建冲突场景数据集（如"老人摔倒但拒绝呼叫急救"），评测机器人伦理推理
- **价值**: 机器人伦理从哲学讨论进入可评测工程阶段，具身 AI 安全关键一步

#### 3. Agent Memory 方向集中爆发（4 篇精选）
- **核心问题**: LLM Agent 执行长程任务时，简单 RAG/滑动窗口记忆不可靠
- **方法**: Graph Memory（图结构化记忆）、State Management（执行状态管理）、Trustworthy Search（可信检索）三套方案平行推进
- **价值**: Agent Memory 从"附加组件"升级为"核心基础设施"，决定 Agent 能走多远
