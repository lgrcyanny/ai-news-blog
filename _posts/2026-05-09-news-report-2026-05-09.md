## 📚 学术研究

### 🌟 重点论文解读

#### 1. StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction
- **arXiv**: [2605.06642](https://arxiv.org/abs/2605.06642)
- **作者**: Xiangyuan Xue, Yifan Zhou, Zidong Wang, Shengji Tang, Philip Torr (Oxford)
- **核心贡献**: 针对 LLM agent 在长程决策中纯反应式（reactive）方法的局限，提出在 agentic RL 中引入**显式的轨迹级策略（trajectory-level strategy）**
- **方法要点**:
  - 从初始任务状态采样一个紧凑策略（compact strategy），后续动作均以此策略为条件
  - 策略生成与动作执行联合训练，采用分层 GRPO-style rollout 设计
  - 引入多样化策略 rollout 和关键自评判（critical self-judgment）机制
- **实验结果**:
  - ALFWorld: **93.1%** 成功率
  - WebShop: **84.2%** 成功率
  - SciWorld: **63.5%** 综合得分，超越前沿闭源模型
- **专业解读**: 这是 agentic RL 方向的重要进展。传统 agentic RL（如 ReAct、Reflexion）本质上是 reactive 的——每一步基于当前观测做决策，缺乏全局规划能力。StraTA 的关键创新在于将策略（strategy）抽象为一个隐变量，在任务开始时生成，然后在整个轨迹中保持一致性。这种 hierarchical 设计解决了两个核心问题：
  1. **探索效率**：有了高层策略指引，agent 不再是盲目试错，而是在策略空间中有方向地探索
  2. **信用分配**：奖励信号可以追溯到策略层面，而非仅归因于单步动作
  这与 DeepMind 的 GATO、Google 的 RT-2 等通用 agent 思路形成互补——StraTA 专注于训练阶段的结构化优化，而非推理时的架构统一。对于使用 GRPO/RLVR 训练 LLM agent 的团队，这是一个非常有参考价值的框架。

#### 2. Skill1: Unified Evolution of Skill-Augmented Agents via Reinforcement Learning
- **arXiv**: [2605.06130](https://arxiv.org/abs/2605.06130)
- **作者**: Yaorui Shi, Yuxin Chen, Zhengxi Lu, Yuchun Miao, Shugui Liu
- **核心贡献**: 提出一个**统一的 RL 框架**，通过单一策略共同进化技能选择（selection）、技能利用（utilization）和技能提炼（distillation）三大能力
- **方法要点**:
  - 所有学习来自单一任务结果信号（single task-outcome signal）
  - 低频趋势信号 → 信用归属于技能选择
  - 高频变化信号 → 信用归属于技能提炼
  - 在 ALFWorld 和 WebShop 上超越现有 skill-based 和 RL 基线
- **专业解读**: Skill1 解决了一个长期困扰 skill-augmented agent 的核心矛盾：技能的选择、使用和新技能的发现往往被独立优化，导致目标冲突。Skill1 的巧妙之处在于通过**单一奖励信号的不同频率成分**来自动分配信用——低频部分反映技能的长期有效性（选择能力），高频部分反映新技能对即时性能的改进（提炼能力）。这种设计避免了手工设计多目标奖励的复杂性，是一个优雅的单目标多能力联合优化方案。

#### 3. Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction
- **arXiv**: [2605.05242](https://arxiv.org/abs/2605.05242)
- **作者**: Zhuofeng Li, Haoxiang Zhang, Cong Wei, Pan Lu, Ping Nie
- **核心贡献**: 提出**Direct Corpus Interaction (DCI)** — agent 直接使用 grep、shell 命令等通用终端工具搜索原始语料库，完全绕过 embedding 模型、向量索引和检索 API
- **关键发现**:
  - 在 BRIGHT 和 BEIR 数据集上显著超越强 sparse、dense 和 reranking 基线
  - 在 BrowseComp-Plus 和多跳 QA 上达到强准确率
  - 不需要离线索引，天然适应动态变化的本地语料
- **专业解读**: 这篇论文挑战了"检索必须通过语义相似度"的传统假设。核心观点是：随着 LLM agent 推理能力增强，检索质量的瓶颈不在于向量表示的质量，而在于**agent 与语料库交互接口的分辨率（resolution）**。DCI 给了 agent 对语料库的"直接访问权"，类似于给人类研究者直接操作文件系统的能力，而非只能通过搜索引擎。这个思路与 Karpathy 的 "software 2.0" 理念相呼应——与其设计复杂的检索 pipeline，不如让 agent 直接操作数据。对于 RAG 系统设计者来说，这意味着在某些场景下，简单工具调用 + 强 LLM 可能比复杂的向量检索 pipeline 更有效。

#### 4. SIRA: SuperIntelligent Retrieval Agent
- **arXiv**: [2605.06647](https://arxiv.org/abs/2605.06647)
- **作者**: Yang Zeyu, Ma Qi, Chen Jason, Shrivastava Anshumali (Rice University)
- **核心贡献**: 将多轮探索性搜索压缩为**单次语料判别性检索行动**
- **方法**: 离线用 LLM 丰富文档缺失搜索词汇 → 在线预测查询遗漏的证据词汇 → 用文档频率统计过滤无效扩展词 → 单次加权 BM25 检索
- **结果**: 在 10 个 BEIR 基准和下游 QA 任务上超越密集检索器和最先进的多轮 agentic 基线
- **专业解读**: SIRA 与上述 DCI 论文形成了有趣的对比——DCI 主张直接操作语料，SIRA 主张将智能集中在检索前的"思考"阶段。SIRA 的核心洞见是：检索的智能不在于多次尝试，而在于**一次精准的判别**。这种"先思考再行动"的思路在 agent 设计中越来越重要。

#### 5. Cola DLM: Continuous Latent Diffusion Language Model
- **arXiv**: [2605.06548](https://arxiv.org/abs/2605.06548)
- **核心贡献**: 提出分层潜在扩散语言模型，通过**分层信息分解**实现非自回归文本生成
- **亮点**: 扩散过程执行的是潜在先验传输（latent prior transport）而非 token 级观测恢复，将全局语义组织与局部文本实现分离；在 ~2B 参数设置下与自回归和 LLaDA 基线严格匹配，缩放曲线可达约 2000 EFLOPs

## 📊 趋势分析

### 本周 AI 领域核心趋势

1. **Agentic RL 进入深水区**: StraTA 和 Skill1 两篇论文同时指向同一个方向——通过结构化的方法（策略抽象、技能库共进化）解决 agentic RL 中的长程决策问题。这是继 ReAct、Reflexion 之后的下一代 agent 训练范式

2. **检索范式重构**: DCI 和 SIRA 两篇论文从不同角度挑战传统 RAG 范式。DCI 主张 agent 直接操作原始数据，SIRA 主张"先思考再检索"。两者共同指向一个结论：**agent 的推理能力越强，对传统检索中间层的依赖就越低**

3. **AI 基础设施军备竞赛**: Anthropic 近万亿美元估值、科技巨头自研芯片、NVIDIA 中国市场归零——AI 基础设施的竞争正在从模型层面扩展到芯片、工具链、生态系统全维度

4. **Coding Agent 生态爆发**: GitHub 上 agent 相关项目持续霸榜，superpowers、everything-claude-code、opencode 等项目均在 15 万星以上，agent engineering 正在成为独立的技术领域

5. **AI 对齐的"Why"转向**: Anthropic 的 "Teaching Claude Why" 研究标志着 AI 对齐从"行为约束"向"理解驱动"转变——不仅要让 AI 做正确的事，还要让它理解为什么这样做是正确的
