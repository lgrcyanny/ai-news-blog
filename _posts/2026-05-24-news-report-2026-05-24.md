### 🔍 重点论文深度解析

#### 1. WorldKV — 世界记忆：Agent 的「海马体」
- **核心问题**: Agent 需要在多轮交互中维护海量上下文，线性增长的 KV cache 不可持续
- **方法**: 提出世界记忆检索与压缩双通道——检索通道快速定位相关信息，压缩通道将无关记忆蒸馏为紧凑表示
- **价值**: 为长期运行的 Agent 提供「恒定内存足迹」方案，是 Agent 从 demo 走向生产的关键基础设施

#### 2. Gated DeltaNet-2 — 线性 Attention 的擦写分离
- **核心问题**: DeltaNet 等线性 Attention 模型「擦除」和「写入」共享同一线性算子，限制了记忆更新精度
- **方法**: 引入独立擦除门和写入门，允许模型对旧信息选择性遗忘、对新信息精确写入，同时保持线性复杂度
- **价值**: 线性 Attention 在保持效率优势的同时逼近完整 Attention 的建模能力，可能成为下一代 LLM 架构标配

#### 3. Maestro — Agent 技能乐团的 RL 指挥家
- **核心问题**: 单个模型无法覆盖所有能力，但如何自动选择组合多个专家模型/技能尚无系统方案
- **方法**: 将技能编排建模为 RL 问题，训练调度器在层级化模型-技能空间中动态选择最优组合，类似「乐团指挥」
- **价值**: 指向 Agent 架构的下一阶段——不再训练更大的单一模型，而是让 RL 学习如何「雇佣」正确的专家
