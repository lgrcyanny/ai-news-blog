### 🔍 重点论文深度解析（3 篇）

#### 1. Qwen-AgentWorld — 语言世界模型赋能通用 Agent
- **核心问题**: Agent 在复杂动态环境中缺乏对动作后果的预测能力
- **方法**: 训练语言世界模型预测动作序列的环境变化，嵌入 Agent 规划循环中做前瞻性决策
- **价值**: 将世界模型从机器人/游戏扩展到通用 Agent，Qwen 生态的差异化竞争武器

#### 2. NatureBench — 编码 Agent 能否匹敌顶会 SOTA？
- **核心问题**: 编码 Agent 声称达到人类水平，但能否复现 Nature 系列论文的实验结果？
- **方法**: 构建 Nature 系列论文复现基准，覆盖 CV/NLP/生物信息学等领域的 50+ 篇论文实验
- **价值**: 首次用顶会论文实验复现率衡量 Agent 科研能力，揭示了当前 Agent 在科学计算中的系统性差距

#### 3. OpenThoughts-Agent — Agent 数据配方
- **核心问题**: Agent 训练数据质量参差不齐，缺乏系统筛选方案
- **方法**: 从轨迹多样性、难度渐进、拒绝采样三个维度定义数据配方，类似 Llama 配方但针对 Agent
- **价值**: 将"数据工程"方法论引入 Agent 训练，预计成为 Agent 模型训练的标配参考
