### 🔍 重点论文深度解析（3 篇）

#### 1. OPID — On-Policy Skill Distillation for Agentic RL
- **核心问题**: Agent RL 训练中，off-policy 数据导致的分布偏移严重损害 skill 学习质量
- **方法**: 提出 on-policy skill distillation 框架，在策略采样过程中同步蒸馏技能表征，消除分布偏移
- **价值**: 与 DanceOPD、OPD-Evolver 形成 on-policy distillation 研究簇，可能成为 agent 训练新标准

#### 2. GUI vs. CLI — 计算机使用 Agent 的执行瓶颈
- **核心问题**: 纯屏幕操作 (GUI) 与技能中介 (CLI/Skill) 两种 agent 范式的效率差异缺乏系统研究
- **方法**: 设计对照实验，测量两种范式在相同任务上的执行时间、错误率和 token 消耗
- **价值**: 直接指导计算机使用 agent 的架构设计选择，技能中介范式在多数场景下更高效

#### 3. The Verification Horizon — 编码 Agent 奖励无银弹
- **核心问题**: 当前 coding agent 普遍依赖 verification reward (测试通过=奖励)，这种范式的上限在哪？
- **方法**: 系统分析 verification-based reward 的信息论极限，证明存在不可逾越的 verification horizon
- **价值**: 警示行业：纯靠测试驱动无法实现真正的代码生成突破，需要更丰富的奖励信号
