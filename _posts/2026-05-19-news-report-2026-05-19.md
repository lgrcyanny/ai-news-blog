### 重点论文解读

#### 1. Solvita: Enhancing LLMs for Competitive Programming via Agentic Evolution

- **来源**: arxiv.org/abs/2605.15301
- **核心贡献**: 将 Agent 进化机制引入竞赛编程——Agent 通过自对弈生成训练样本，迭代改进解题能力，无需额外人工标注
- **关键方法**: Agent 在编程竞赛环境中自主解题，成功/失败轨迹分别作为正/负样本蒸馏回模型；多轮迭代中 Agent 能力逐步提升，类似 AlphaGo 的自对弈进化
- **价值**: 这是「Agent 自我进化」范式的又一实例，验证了自对弈 + 迭代蒸馏在编程推理场景的有效性。与昨日 Self-Distilled Agentic RL 思路相近但聚焦编程领域，暗示自蒸馏可能成为跨领域的通用 Agent 训练范式

#### 2. Nudging Beyond the Comfort Zone: Efficient Strategy-Guided Exploration for RLVR

- **来源**: arxiv.org/abs/2605.15726
- **核心贡献**: 解决 RLVR (Reinforcement Learning with Verifiable Rewards) 中 Agent 探索不足的问题——Agent 倾向于待在「舒适区」只执行已知能获得奖励的动作，本文提出策略引导的探索机制迫使 Agent 尝试新策略
- **关键方法**: 维护一个探索策略网络，主动引导 Agent 偏离当前最优策略；结合 curiosity-driven 探索和策略多样性约束，在保持训练稳定性的同时扩大探索范围
- **价值**: 对 Agentic RL 的直接实用价值——当前 RLVR 最大的痛点是 Agent 学到的策略过于保守（只调用已知工具，不敢尝试新组合）。本文的「舒适区突破」机制如果实用化，可能显著提升 Agent 的工具发现和组合能力

#### 3. Distilling Long-CoT Reasoning through Collaborative Step-wise Multi-Teacher Decoding

- **来源**: arxiv.org/abs/2605.02290
- **核心贡献**: 提出多教师协作逐步解码蒸馏方法——多个教师模型在推理链的每一步协作生成最优中间步骤，学生模型学习的是「多专家共识」而非单一教师的推理路径
- **关键方法**: 每一步推理时，多个教师模型独立生成候选步骤，通过协作机制（如投票或置信度加权）选出最佳步骤；学生模型被训练来复现这个「协作后的最优路径」
- **价值**: 相比传统的单一教师蒸馏，多教师协作可能产生更鲁棒的推理链，减少单一模型的系统性偏差。对长思维链推理的实用意义：如果学生能从多个强模型的最佳部分学习，可能在小模型上实现接近多模型 ensemble 的推理质量

## 💡 今日洞察

1. **Agent 自我进化范式正在固化** — Solvita（竞赛编程）+ 昨日 Self-Distilled Agentic RL（通用）形成了清晰的模式：自对弈生成训练数据 → 迭代蒸馏 → 能力提升。这不只是论文巧合，而是一个研究范式正在形成。如果这一范式在更多领域（数学、科学、工具使用）得到验证，Agent 训练将从「人工 prompt 工程」全面转向「自动能力进化」

2. **RLVR 探索效率是 Agentic RL 的下一个关键瓶颈** — Nudging Beyond the Comfort Zone 直接指出：当前 RLVR 训练的 Agent 太保守，只做已知能得分的事。这对 Agent 工具使用的启示是——如果你不给 Agent 探索激励，它永远不会发现工具的创造性组合。这篇论文的「舒适区突破」机制可能就是解决这个瓶颈的钥匙

3. **小模型 + 好 Agent 框架 = 大模型平替** — smallcode（4B 模型 87% 基准）和 opensquilla（Token 高效 Agent）共同指向一个趋势：Agent 框架的质量正在变得比模型大小更重要。如果这个趋势持续，Claude Code $200/月 vs Goose 免费的对比将越来越偏向后者

4. **AI 行业正面临「合法性危机」** — Musk v. Altman 判决 + Eric Schmidt 被嘘 + ArXiv 封禁 AI slop，三条新闻在 48 小时内接连出现，不是巧合。AI 行业需要从「技术乐观主义」叙事转向「负责任创新」叙事，否则公众信任的流失将转化为更严厉的监管
