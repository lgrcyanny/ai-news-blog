## 今日结论

1. **Skill 已从“外挂提示词”变成 Agent 训练的核心对象。** AUSO 研究其从教师监督到内部知识、再到按动作选择性调用的生命周期；这与上周 SkillGate/BPS 的选择与预算优化形成连续主线。
2. **小模型有机会成为大 Agent 的运行时副驾驶。** COTA 不要求辅助模型会解题，只让它比较同前缀分支并给出非强制建议；若能在生产任务复现，成本可能低于再部署一个强 critic。
3. **安全对齐的关键问题仍是“何时干预”。** CLEAR 用连续门控的 LoRA adapter 在 Llama-3-8B 上将 HarmBench ASR 从 32.3% 降至 0.5%，同时比全局 SFT/LoRA 高出最多 7.1 个 GSM8K 点；但其跨攻击、跨模型泛化尚待验证。
4. **OpenAI × AWS/Kiro 的信号不只是接入新模型，而是“规格驱动 + 分层模型”的工程经济学。** OpenAI 报告 GPT‑5.6 Terra 在 Kiro 的 Terminal-Bench 2.1 测试中，每个成功任务成本约低 82%；这是受特定 harness 和基准约束的作者结果，不能直接外推到真实代码库。

## 研究前沿

### 1. AUSO：让 Skill 从被灌输到按动作选择性生效

**论文 / 日期：** [AUSO: Action-Level Unified Skill Optimization from Internalization to Utilization](https://arxiv.org/abs/2608.21292)，2026-08-21 提交。

**问题与机制。** 现有 Agent Skill 方法往往三选一：把 Skill 永远置于模型外、完全蒸馏到模型内，或按整条轨迹成败决定是否使用。作者认为这忽略了 Skill 在不同训练阶段的角色，也错误地将同一轨迹中的所有动作等权。AUSO 先联合教师指导与环境回报取得基础能力，随后侧重 outcome RL；成熟阶段再对每个采样动作比较“有 Skill / 无 Skill”两种上下文，用动作级信息信号调制轨迹 advantage。

**关键结果（作者主张）。** 在 ALFWorld、WebShop、SearchQA 上，相对竞争方法持续提升任务表现和 OOD 泛化；摘要未提供绝对分数或方差。

**增量。** 它把 Skill 的问题从单纯检索或一次性蒸馏，改写为“何时将外部知识转化为内部策略、何时不应让它干扰”的连续优化。这与昨天 BPS 的 context 预算选择互补：一个处理训练中的内化和动作信用，另一个处理推理时集合选择。

**局限 / 工程价值。** 动作级反事实比较会增加训练 rollout 成本，且在复杂工具链中“有无 Skill”的对照未必严格等价。arXiv 未列公开代码；可先将其思想用于重要动作的 ablation logging，而非直接采纳完整训练法。

### 2. COTA：不让小模型解题，只让它比较下一步

**论文 / 日期：** [Don't Solve, Just Compare: Tiny Advisors for Runtime Intervention in LLM Agents](https://arxiv.org/abs/2608.21027)，2026-08-21 提交。

**问题与机制。** 长程 Agent 出错后，检测失败不足以帮助恢复；常见方案又需要一个同等强的求解器或生成具体修正的 critic。COTA 训练一个微型比较器，对来自同一前缀的反事实分支判断哪个后续更好；多次比较决定是否干预，把偏好的候选以非绑定建议返还给原 Agent 重新规划。

**关键结果（作者主张）。** 在 WebShop、ALFWorld、tau³-Retail，三种 actor、共九组设置中均有改善，并超过论文选择的基线；摘要未披露每项提升和比较器规模。

**增量与边界。** 其可贵之处是将“构造性干预”降格为偏好比较问题，理论上可用远弱于 actor 的模型完成。真实生产中，采样多分支会抬高时延与 token 成本，且 comparator 的偏好是否在分布外持续有效仍未知。未见代码 / 项目页。

**复现 / 工程价值。** 中高。适合高价值、可容忍少量分支预算的 Agent；应以“额外 rollout 成本、成功率、人工升级率”三项共同评估，而非只看最终成功率。

### 3. CLEAR：用连续 adapter 路由降低安全—效用的全局副作用

**论文 / 日期：** [CLEAR: Continuous Latent Adapter Routing for Utility-Preserving LLM Safety Alignment](https://arxiv.org/abs/2608.21278)，2026-08-21 提交。

**问题与机制。** 全局安全 SFT 或 LoRA 会在良性输入上也改变模型行为，形成安全与通用能力的拉扯。CLEAR 冻结底座，以隐藏状态上的轻量 gate 连续控制安全 LoRA adapter 的激活强度，目标是仅在风险输入上增强安全行为。

**关键结果（作者主张）。** 在 Llama-3-8B-Instruct 上，HarmBench ASR 从 **32.3% 降至 0.5%**；相对全局 SFT/标准 LoRA，GSM8K 最高多 **7.1 个百分点**，同时保留大部分底座效用。

**增量与边界。** 比二元风险分类器更细粒度，也比整模型重训轻量。风险是 gate 本身可能成为攻击面：对抗性措辞、长上下文污染或多轮组合攻击可能让它低激活；单一 HarmBench 与数学效用不能替代全面安全评估。arXiv 未列代码链接。

**复现 / 工程价值。** 中。适合研究“条件化安全层”，不宜据此直接宣称生产级防护；需要与 jailbreak、多语种、工具调用、拒答质量和延迟一并压测。

### 4. SciUnlearn：科学结论的删除远比删除一条训练样本困难

**论文 / 日期：** [Can Scientific Claims Be Removed from Large Language Models? A Systematic Evaluation of Claim-Level Unlearning](https://arxiv.org/abs/2608.20960)，2026-08-21 提交；EMNLP 2026 Main Conference。

**问题与机制。** 科学语料中的结论会被修正、撤稿或淘汰；模型若继续输出过时主张，会影响科研工作流。已有 unlearning 多在实例级衡量忘记，而单个科学结论具有相互关联、随时间演变、可多种表述恢复等特点。作者提出 Scientific Claim Unlearning 与 SciUnlearn benchmark。

**主要发现（作者主张）。** 当前 unlearning 方法无法有效移除结论级知识，许多结果只是表层压制而非真正消除；摘要未给具体攻击成功率或能力保持数字。

**增量与边界。** 这将“删除”从 token/文档级提升到可验证命题级，对科学助手、法律和医疗知识更新特别重要。结论级标注成本高，且缺少数据的模型还可能通过相关事实重新推导该结论；benchmark 的 claim 覆盖和探测方式决定其可信度。当前未见代码 / 数据入口。

## 商业动态

### GPT‑5.6 进入 AWS Kiro 的规格驱动编码工作流

**事实。** OpenAI 于 [2026-08-24 宣布](https://openai.com/index/gpt-5-6-in-kiro/) GPT‑5.6 的 Sol、Terra、Luna 已可在 AWS 的 Kiro 使用。Kiro 将需求拆为规格、技术设计和可执行任务，并支持在关键节点人工审阅、基于属性的测试；官方称 Kiro 中的 GPT‑5.6 Terra 在 Terminal-Bench 2.1 上每个成功任务约降低 **82%** 成本。

**意义。** 这让模型分层、工程规格与验证步骤成为同一个产品闭环：将高规格任务交给更强模型、把更确定的执行与测试交给便宜模型，是 Agent 成本曲线的实用路径。

**不确定性。** 82% 是 OpenAI/AWS 在特定 harness 与 benchmark 的测试，未给出完整任务分布、失败成本和真实仓库的长期统计；企业采用前仍应在自身代码库测端到端吞吐、返工率、审查负担与 token 成本。

**其余公司：无高价值新增。** 核验 Anthropic、Google DeepMind、Meta、NVIDIA、AWS、Mistral、Databricks、Snowflake 与国内 ByteDance Seed、Qwen、DeepSeek、MiniMax、百度、智谱、Moonshot、美团、阿里技术官方入口后，未发现过去 24 小时可确认的重大模型能力、价格或可用性变化。Google Research 8 月 21 日新增可穿戴传感器生物标志物研究，属于垂直科研进展，未改变通用 AI 产品格局。
