### 🔍 重点论文深度解析（≤ 3 篇）

#### 1. DOPD — 双路 On-Policy 蒸馏
- **核心问题**: 传统 LLM 蒸馏使用离线数据，教师-学生分布偏移导致能力整合低效
- **方法**: 同时从教师和学生策略在线采样，构建双重 on-policy 轨迹，用对比学习对齐分布
- **价值**: 为多模型能力融合提供新路径，可能替代 RLHF 的部分功能

#### 2. Orca — 世界在心智之中
- **核心问题**: 像素级世界模型计算开销大、泛化差
- **方法**: 提出心智世界表征，将物理世界抽象为可推理的符号+向量混合空间，不依赖像素重建
- **价值**: 大幅降低世界模型推理成本，向通用世界理解迈进

#### 3. Dockerless — 编码 Agent 无环境验证
- **核心问题**: 编码 Agent 验证依赖 Docker 沙箱，部署复杂、资源消耗大
- **方法**: 纯静态分析程序验证器，通过符号执行在不运行代码的情况下验证正确性
- **价值**: 让 Coding Agent 在资源受限环境（边缘设备/Serverless）中也能可靠运行
