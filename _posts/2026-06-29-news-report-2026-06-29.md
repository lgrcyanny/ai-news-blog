### 🔍 重点论文深度解析（3 篇）

#### 1. OPID — On-Policy 技能蒸馏赋能 Agentic 强化学习
- **核心问题**: 现有 agent skill 学习依赖离线数据，分布偏移导致策略退化
- **方法**: 提出 on-policy distillation 框架，在 agent 与环境交互过程中实时蒸馏技能，消除 offline-online gap
- **价值**: 为 Agentic RL 提供新的训练范式，可能替代当前主流 offline RL 方法

#### 2. Verification Horizon — Coding Agent 奖励函数的无银弹定理
- **核心问题**: 所有基于验证的 coding agent 奖励函数都存在可利用边界
- **方法**: 理论证明+大规模实验，揭示 reward hacking 是结构性而非工程性问题
- **价值**: 对 SWE-bench 等主流评测的可靠性提出根本性质疑，推动新评估范式

#### 3. In-Context World Modeling — 机器人控制的上下文世界模型
- **核心问题**: 机器人需要为每个新环境重新训练世界模型
- **方法**: 将世界建模嵌入 Transformer 的 in-context learning 机制，单模型跨场景泛化
- **价值**: 大幅降低机器人部署的样本复杂度，向通用操作迈出关键一步
