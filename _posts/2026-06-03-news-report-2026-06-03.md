### 🔍 重点论文深度解析（3 篇）

#### 1. Harness-1 — 搜索 Agent 的 RL 训练框架
- **核心问题**: 搜索 Agent（如 Deep Research）目前主要靠 Prompt 工程，缺乏系统性 RL 训练方法
- **方法**: 提出 State-Externalizing Harness——将 Agent 内部搜索状态外化，使 RL 奖励信号能够对齐搜索行为，类似"给搜索过程装监控"
- **价值**: 将搜索 Agent 从启发式调参带入 RL 工程化时代，与昨日 GrepSeek 形成"能力-训练"互补

#### 2. Multi-Agent Computer Use — 多 Agent 协作计算机操作
- **核心问题**: 现有 GUI Agent 都是单打独斗，复杂计算机操作需要多 Agent 协同（如一个 Agent 查资料、一个整理、一个执行）
- **方法**: 将计算机操作分解为可并行子任务，多 Agent 共享屏幕状态协调执行
- **价值**: Agent 协作粒度从"任务级"细化到"操作级"，是 Agent 团队化的关键基础设施

#### 3. SkillAdaptor — Agent 技能自适应进化
- **核心问题**: Agent 技能（Skills/Prompts）是静态的，无法根据执行反馈自动改进
- **方法**: 从 Agent 轨迹中学习技能调整策略——什么场景用什么技能变体，自动蒸馏最佳实践
- **价值**: 技能从"手写一次用一辈子"走向"越用越好"，与昨日 COLLEAGUE.SKILL（技能蒸馏）形成"生产-进化"闭环
