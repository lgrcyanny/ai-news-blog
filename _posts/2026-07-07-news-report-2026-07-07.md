### 🔍 重点论文深度解析（≤ 3 篇，每篇 3-4 行）

#### 1. Embodied.cpp — 具身 AI 的 "一次编写，处处推理"
- **核心问题**: 具身AI模型部署严重依赖特定硬件平台，缺乏跨机器人移植方案
- **方法**: C++ 推理运行时，支持从 NVIDIA Jetson 到 Raspberry Pi 的异构硬件，ONNX 模型一键部署
- **价值**: 降低具身AI部署门槛，让实验室模型快速落地到真实机器人

#### 2. Securing the AI Agent — 多层 Agent 红队测试统一框架
- **核心问题**: Agent 安全研究碎片化，提示注入/工具滥用/记忆投毒各自为战
- **方法**: 统一红队测试框架，覆盖输入层/推理层/工具层/记忆层四层攻击面，提供标准化评估协议
- **价值**: 为 Agent 安全研究提供统一基准，类比 OWASP 对 Web 安全的意义

#### 3. Atomic Task Graph — Agent 规划的统一图框架
- **核心问题**: LLM Agent 规划方法（ReAct/Plan-and-Solve/Tree-of-Thought）各自为政，无法互操作
- **方法**: 将任务分解为原子操作节点，以有向无环图统一表达所有规划策略
- **价值**: 让不同规划算法在同一框架下比较，推动 Agent 规划研究标准化
