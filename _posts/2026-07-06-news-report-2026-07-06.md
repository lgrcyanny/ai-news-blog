### 🔍 重点论文深度解析（3 篇）

#### 1. AgenticSTS — 长程 LLM Agent 记忆容量压力测试
- **核心问题**: LLM Agent 在长程任务中上下文窗口不断膨胀，决策质量如何退化？
- **方法**: 构建有限记忆测试平台，系统性地限制 Agent 可用记忆容量并测量任务完成率
- **价值**: 首次量化 Agent 在信息过载下的性能曲线，直接指导 Agent 记忆架构设计

#### 2. WorldDirector — 世界模拟器的持久记忆突破
- **核心问题**: 现有世界模拟器在长时间交互中丧失一致性，无法记住已发生的状态变化
- **方法**: 引入持久动态记忆模块，将世界状态编码为可查询的键值存储
- **价值**: 从"一次性快照"到"持续世界"，AI 世界模型的里程碑进步

#### 3. SkillCoach — 让 Agent 技能评估随能力进化
- **核心问题**: Agent 能力在进化，但评测标准（rubrics）一成不变，越来越不准确
- **方法**: 评分标准与 Agent 能力同步进化，LLM 自动生成适配当前能力水平的新评分维度
- **价值**: 解决"评测过时"的系统性问题，Agent 评测从静态走向自适应
