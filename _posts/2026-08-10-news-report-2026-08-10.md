### 1. AgentOPSD: Recursive Self-Distillation for Agentic RL ⭐85
> **一句话**：让 RL agent 通过自我蒸馏从失败轨迹中学习，递归提升策略质量

Agent 强化学习的核心痛点：高质量训练数据依赖人工标注。AgentOPSD 提出递归自蒸馏框架——agent 在环境中执行→收集成功/失败轨迹→用成功轨迹蒸馏失败轨迹→递归迭代。无需外部 reward model，agent 自我进化。实验在 WebArena、OSWorld 等 benchmark 上显著提升。

| 亮点 | 说明 |
|------|------|
| 递归自蒸馏 | 成功轨迹教失败轨迹，自动生成训练信号 |
| 无需标注 | 零人工干预的自我改进循环 |
| 跨环境泛化 | Web/OS/Code 多场景验证 |

### 2. OSReward: Standardized Evaluation for CVW Reward Models ⭐67
> **一句话**：首个跨平台计算机操作奖励模型标准化评测基准

计算机操作 (Computer-Use) 领域奖励模型林立，但各家用各的 benchmark，无法横向比较。OSReward 建立统一评测框架，覆盖 Windows/macOS/Linux 三大平台，定义标准化任务集和指标，评估现有 RM 的跨平台泛化能力。

| 亮点 | 说明 |
|------|------|
| 首次标准化 | CVW 领域 RM 评测从"各自为政"到统一基准 |
| 跨平台 | Win/Mac/Linux 三平台覆盖 |
| 揭示泛化差距 | 现有 RM 跨平台迁移时性能下降显著 |

### 4. EnvACE: Internalizing Environment Dynamics via World Rehearsal ⭐38
> **一句话**：让 RL agent 在"脑中排练"环境动态，减少真实交互次数

Agent RL 的样本效率问题——需要大量环境交互。EnvACE 提出 World Rehearsal：agent 先学习环境的世界模型，然后在决策前进行"心理排练"（mental rehearsal），预测动作后果。显著减少实际环境交互需求。

🔗 `arxiv:2608.06197`

### 5. PaDoc: Layout-Grounded Parallel Decoding for Document Parsing
> **一句话**：利用文档布局信息实现并行解码，文档解析速度大幅提升

传统文档解析逐 token 顺序生成。PaDoc 利用文档的 2D 布局结构——不同区域（标题/段落/表格）天然解耦，可并行解码。在发票、合同、学术论文等结构化文档上实现 3-5x 加速。

🔗 `arxiv:2608.06146`
