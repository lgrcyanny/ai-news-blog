### 🔍 深度分析（3 篇）

- **Repo-To-Skill（2609.02749，413↑，BAAI）**：自主 agent 跑 ML 研究已端到端，但"把方法真正跑通"的 know-how（operational knowledge）仍在 agent 之外——散落在仓库/论文里、为人读而写、大到无法在任务中加载。本文用 DisCo 研究 agent 把仓库蒸馏成紧凑、可验证的 skills，多项 benchmark 上显著提升自主研究表现。与 GitHub 上 anthropics/skills、mattpocock/skills 等仓库井喷同频：**技能正成为 agent 的标准化知识载体（AI4AI 技能经济）**。

- **HarnessDev（2609.01437，178↑）＋ Aspire（2608.31111，142↑，均 ByteDance Seed）**：同一 org 两条线把"agent 元能力"推向可评测。HarnessDev 指出换 harness 不动权重就能大幅改变任务表现，因此把评测从任务输出移到"能否自己造出并迭代可运行的执行基础设施"——发现自建 harness 能力/效率方差大、且跨模型迁移差。Aspire 则反对"人类给定任务+指标的自进化是假自进化"，改从模糊自然语言目标出发，暴露目标解读、数据选择、权重级稳定提升三大难点。**自造工具、自定目标，正成为下一代 agent 的考题**。

- **SolarWM（2609.02886，133↑，CUHKSZ）**：交互式视频世界模型训练被"数据异构 × backbone 异构"卡住（时间尺度/相机几何/画质/动效/标注风格各异，生成器表征不一）。SolarWM 给出可重配置多模态数据管线 + 统一训练配方 + 长程实时 rollout 的全开放基座。接续 H3-World/ZimaBlue 的"世界模型从会生成走向可控制、可行动"主线，把缺位的开源基建补齐。
