### 🔍 重点论文深度解析

#### 1. Minimal RLVR — 最少 RLVR 训练即可外推
- **核心问题**: RLVR 为何有效？需要多少训练才能让 LLM 在推理时泛化？
- **方法**: 证明 RLVR 的泛化增益来自训练中 rank-1 轨迹方向的外推，只需极少训练样本即可激活这一机制
- **价值**: 如果成立，意味着 RLVR 训练成本可大幅削减；同日 Unlearnability 论文形成有趣的学术对话

#### 2. SaaSBench — 企业 SaaS 编程 Agent 评测
- **核心问题**: 现有 coding agent 评测停留在 LeetCode/CRUD，真实企业 SaaS 工程（多服务、遗留代码、复杂依赖）完全是盲区
- **方法**: 构建面向企业 SaaS 场景的长周期评测基准，涵盖微服务调试、数据库迁移、API 兼容等真实工程任务
- **价值**: Coding Agent 从「刷题」走向「干活」的关键评测里程碑

#### 3. IndusAgent — Agent 范式进入工业视觉
- **核心问题**: 工业异常检测依赖封闭集分类，无法处理开放场景下的新型缺陷
- **方法**: 将 Agent 工具调用框架（视觉工具、查询工具、推理工具）引入异常检测，让模型动态选择检测策略
- **价值**: Agent 范式从对话/Coding/GUI 跨界到工业 CV，证明「一切皆 Agent」的趋势不可逆
