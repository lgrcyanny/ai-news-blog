### 🔍 重点论文深度解析（3 篇）

#### 1. SWE-Explore — 评测 Coding Agent 如何探索代码仓库
- **核心问题**: 当前 coding agent 在陌生仓库中的探索策略缺乏系统评测
- **方法**: 构建多语言、多规模的仓库探索 benchmark，量化 agent 的文件定位、依赖理解、代码导航能力
- **价值**: 为改善 coding agent 的实际工程可用性提供了标准化评估维度

#### 2. LatentSkill — In-Context 技能到 In-Weight 潜在技能
- **核心问题**: LLM Agent 依赖长 prompt 携带技能，效率低且不可持久
- **方法**: 通过蒸馏将 In-Context 文本技能压缩为模型权重的潜在技能向量，在推理时直接激活
- **价值**: 标志着 Agent 技能从"外挂 prompt"到"模型原生能力"的范式迁移

#### 3. FlashMemory-DeepSeek-V4 — 超长上下文闪电索引
- **核心问题**: 超长上下文（100K+ tokens）的注意力计算开销巨大
- **方法**: Lookahead Sparse Attention 在检索前预判关键 token 位置，实现亚线性复杂度的上下文索引
- **价值**: 为实用化百万 token 级上下文窗口提供了工程可行路径
