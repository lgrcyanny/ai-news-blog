### 🌟 PapersWithCode Trending — 本周新上榜论文

> 以下论文在 5/18 的 PWC trending 榜单中首次出现（与 5/17 报告无重叠）。

#### 1. Self-Distilled Agentic Reinforcement Learning

- **核心贡献**: 提出自蒸馏 Agentic RL——Agent 通过自我博弈生成训练数据，用课程学习逐步提升能力，无需外部 reward model 或人类反馈
- **关键方法**: Agent 在环境中自主探索，将成功轨迹蒸馏为训练信号；课程学习确保从简单任务逐步过渡到复杂任务；自我博弈机制使 Agent 可以不断挑战更强的「对手」（自己的历史最佳版本）
- **专业解读**: 这是 Agentic RL 方向一个非常重要的工作。当前 RLHF 的核心瓶颈在于人类反馈的昂贵和 reward model 的不可靠——Self-Distilled RL 试图完全绕过这两个问题。如果成功，意味着 Agent 可以在没有人类监督的情况下自主进化。但关键挑战在于：
  - **奖励 hacking 风险**: 自我博弈中的 Agent 可能学会利用环境漏洞而非真正提升能力
  - **课程设计**: 自动课程学习本身就是一个未解决问题——如果课程设计不当，Agent 可能陷入局部最优
  - **与 GenericAgent 的联系**: 昨天的 GenericAgent 优化 token 效率，Self-Distilled RL 优化任务能力——两者结合可能产生「既聪明又省钱的 Agent」
- **对 Agentic RL 的启示**: 自蒸馏 + 自我博弈的组合可能是实现 scalable agent training 的关键路径——类似于 AlphaGo Zero 之于围棋，如果能泛化到任意工具使用场景，影响将是巨大的

#### 2. ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration

- **核心贡献**: 用对抗式多 Agent 协作实现自主科研——多个 Agent 分别扮演研究者、评审者、反对者角色，通过辩论驱动从文献检索到论文撰写的全流程
- **关键方法**: 对抗式协作（而非单纯合作），评审 Agent 主动挑刺，反对 Agent 提供反面论证，研究者 Agent 针对性改进。类似「内部 peer review」机制
- **专业解读**: 相比之前的 OpenDevin（通用软件 Agent），ARIS 更进一步——不仅执行任务，还能自主发现研究问题、设计实验、撰写论文。其「对抗式协作」设计很巧妙：传统多 Agent 系统通常追求共识，ARIS 故意引入冲突来提升输出质量。这与学术 peer review 的本质逻辑一致——好的研究是通过批评和反驳打磨出来的。但需要警惕的是：如果底层 LLM 本身的知识是幻觉/错误的，对抗辩论不会产生真知，只会产生更精致的错误
- **与 TradingAgents 的共鸣**: 两者都采用多 Agent 辩论架构——TradingAgents 用于金融决策，ARIS 用于科学研究。多 Agent 辩论正在成为一个跨领域的通用范式

#### 3. Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory

- **核心贡献**: 专为生产环境设计的 Agent 长期记忆系统——支持可扩展的记忆存储、检索和更新
- **关键方法**: 分层记忆架构（短期/长期/情景记忆），支持语义检索和时效性衰减，针对 Agent 的多轮交互和跨 session 记忆需求优化
- **专业解读**: 当前大多数 Agent 是「无状态」的——每次对话从零开始。Mem0 试图给 Agent 装上真正的「记忆」。这看似是工程问题，实际是研究问题：Agent 应该记住什么？如何避免记住错误信息？如何遗忘过时信息？——这些都是开放问题。Mem0 的价值在于提供了一个生产级的 baseline，让 Agent 开发者不必从零实现记忆模块
- **与 OpenViking 的互补**: GitHub trending 上的 OpenViking（火山引擎开源）也在做 Agent 上下文数据库——记忆层正在成为 Agent 基础设施的关键战场

#### 4. Orthrus: Memory-Efficient Parallel Token Generation via Dual-View Diffusion

- **核心贡献**: 用双视图扩散模型实现内存高效的并行 token 生成——突破传统自回归模型的串行瓶颈
- **关键方法**: 将 token 序列分为两个视图并行生成，通过扩散过程协调两个视图的一致性
- **专业解读**: 自回归模型的最大工程瓶颈是「串行生成」——必须一个一个 token 地输出。Orthrus 的并行生成如果能在保持质量的前提下实现，对推理延迟的改善将是数量级的。但扩散模型在文本生成上的质量一直不如自回归模型（这就是为什么 GPT 系列坚持自回归），Orthrus 需要在质量和速度之间找到平衡

#### 5. Is Grep All You Need? How Agent Harnesses Reshape Agentic Search (ArXiv, 2026-05-14)

- **核心贡献**: 对当前 Agent 信息检索架构提出根本性质疑——研究发现，在很多场景下，简单的 grep/关键词搜索的效率和效果不亚于复杂的语义检索 pipeline
- **关键方法**: 系统性地对比了 Agent 搜索架构中的多种设计选择（语义检索 vs 关键词检索、上下文窗口 vs 外部检索、单步 vs 多步检索），发现 Agent harness（检索框架）的设计对最终效果的影响可能大于底层模型能力
- **专业解读**: 这是一篇可能会让很多做 RAG 的公司感到不安的论文。它的核心洞察是：Agent 场景下，「聪明的检索策略」可能比「强大的语义模型」更重要。如果 grep + 简单过滤能达到和复杂 vector search 类似的效果，那么当前大量 RAG 公司的技术壁垒就需要重新审视。但论文标题的「Grep 就够了」是一种故意夸张——在需要语义理解的场景（如「找关于气候变化的悲观预测」），grep 显然不够。真正的贡献在于提醒我们：不要为了用 fancy 技术而用 fancy 技术

- **事件**: Bloomberg 的 Mark Gurman 报道，iOS 27 中全新 Siri 将支持自动删除对话记录——用户可以选择在一定时间后自动清除聊天历史

- **专业解读**:
  - Apple 的 AI 战略越来越清晰：不在模型能力上硬拼（那是 OpenAI/Google 的战场），而是在「信任」上建护城河。auto-deleting chats 是一个强烈的隐私信号——「你的对话不会永远留在 Apple 的服务器上」
