### 🔍 重点论文深度解析（3 篇）

#### 1. S-Agent — 空间工具调用赋能 Agent 空间推理
- **核心问题**: 当前 VLM Agent 在 3D 空间推理中依赖静态、无状态的孤立视觉观测，无法处理连续演化空间
- **方法**: 提出空间工具调用 Agent 范式，赋予 Agent 主动采样 3D 空间信息的能力，实现状态感知的空间推理
- **价值**: 为具身 Agent、AR/VR 导航等场景提供空间智能基础，突破 VLM 的 2D 推理局限

#### 2. Current World Models Lack Persistent State Core — 世界模型架构缺陷
- **核心问题**: 当前世界模型仅追求逐帧渲染逼真度，缺乏随时间演化的内部持久世界状态
- **方法**: 系统性分析世界模型架构，证明缺失持久状态核心导致物理一致性崩溃，提出状态核心设计原则
- **价值**: 继 ImageWAM 质疑视频生成必要性后，从架构层面揭示世界模型根本缺陷，推动下一代世界模型设计

#### 3. ENPIRE — 真实世界 Agent 策略自改进
- **核心问题**: 灵巧机器人操作依赖大量人工监督，编码 Agent 的仿真策略难以迁移到真实世界
- **方法**: 让编码 Agent 直接在真实机器人上闭环执行-观察-改进策略，自主迭代优化操作代码
- **价值**: 首次实现真实世界 Agent 策略闭环自改进，为通用物理智能的规模化铺路
