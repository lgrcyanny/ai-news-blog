### 🔍 深度分析（3 篇）

- **Show-Harness（2609.10522，96↑）**：核心是"具身 harness"——不微调 VLM 本体，而是暴露一组离散语义动作单元（action units）让 VLM 用自然语言推理，embodiment 专属控制细节下沉到接口层。**分析：与月榜 HarnessDev、NeoHorse-1 形成同一叙事——"harness 即能力"，模型不变、接口一变就换任务域；这也是通用 VLM 通向机器人控制的最低成本路径，比端到端 VLA 更容易复用现有基座。**
- **AgentGrad（2609.08572，64↑）**：指出多 agent 系统 prompt 优化的文本梯度法在两阶段都有缺陷（哪一步、往哪改），提出干预引导：先定位真正造成失败的 agent 节点，再生成定向文本梯度。**分析：MAS 的性能瓶颈往往在"最弱一环"而非所有 prompt，干预式定位把优化从"全局改稿"变成"外科手术"，方向上与 9 月主线（Repo-To-Skill 式技能蒸馏）互补——一个蒸馏能力、一个精修协同。**
- **Programmable World Model（2609.10540，62↑，Alaya Lab）**：现有视频世界模型画面逼真但缺乏持久状态与规则约束；本工作让 agent 把自然语言指令落地为可执行程序，由程序维护世界状态、视频模型只负责观测渲染。**分析：这是世界模型从"像素模拟"走向"可编程沙盒"的关键抽象——状态与渲染分离后，物理规则/业务规则可插拔、可验证，为 agent 在想象环境中做确定性实验铺路；与同日 SyncWorld（视觉校准做零样本模拟器）共同指向"可控 rollout"这一机器人/agent 训练的刚需。**

**其余看点**：评测/审计簇——SAEScientist-Bench（2609.09113，SAE 可解释性自主研究基准）、DCP 发现认证协议（2609.09219，Gate1 密封评测+Gate2 信息匹配，"分数不证明发现"）、SchemeArena（2609.08126，LLM agent scheming 分解压测）、Φ-Bench（2609.10226，LLM 能否工程化自己的基础设施）；世界模型/具身——SyncWorld（2609.09155，视觉校准零样本模拟器）、Puppeteer（2609.00369，物体接地+姿态感知的共语手势生成）；训练/推理——Revisiting Complete Reasoning Traces（2609.07103，完整轨迹 SFT 未必更优）、Train Smarter Not Harder（2609.06806，主动学习切换信号）、Difficulty-Adaptive Tree-Structured PO（2609.08650，RLVR 扩展推理覆盖）；垂直数据/应用——DianShi-RxnDB（2609.06703，全自动有机反应数据平台）、AgenticGen（2609.09187，奖励引导 agentic 广告视频生成）、Three-Layer Caching for LLM Web Search（2609.05463，商品级 CPU 低延迟搜索）、Why Is Video Still So Expensive?（2609.10355，视频/视听 LLM 推理效率综述）。
