### 🔍 重点论文深度解析

#### 1. Vidu S1 — 实时交互式视频生成
- **核心问题**：现有视频生成模型推理耗时数分钟，无法支持实时交互
- **方法**：通过流式扩散架构 + 推理优化，将端到端延迟压缩至秒级，支持用户实时笔刷/文本控制
- **价值**：视频生成从"离线渲染"走向"实时交互"，打开游戏/设计/Creation Tool 新场景

#### 2. UniClawBench — 主动式 Agent 评测
- **核心问题**：现有 Agent 基准都假设任务被"喂给"Agent，不测主动性
- **方法**：构建 120+ 真实世界任务场景，要求 Agent 主动发现、规划、执行，而非被动等待指令
- **价值**：从"听话的 Agent"到"会找事的 Agent"，评测范式升级

#### 3. Remember When It Matters — 主动记忆
- **核心问题**：长程 Agent 面临上下文窗口压力，全量记忆效率低
- **方法**：训练一个 Memory Gate 模块，判断当前信息是否值得写入长期记忆，实现选择性存储
- **价值**：记忆 ≠ 存储全部，选择性记忆让 Agent 在长程任务中更高效
