## 📄 今日论文（HF Daily Papers, ≤5）

### 1. AREX: 递归自改进深度研究 Agent
- **机构**: BAAI（北京智源） | 👍 139
- **核心**: 让 Agent 在深度研究任务中通过自我反思、工具调用和知识积累实现递归式能力自改进
- **亮点**: 不依赖外部 RL 训练，Agent 在推理过程中自发改进；提出 Recursive Self-Improvement Loop 框架

### 2. SANA-Video 2.0: 混合线性注意力视频生成
- **机构**: NVIDIA | 👍 27
- **核心**: 用 Hybrid Linear Attention + Attention Residuals 替代传统 full attention，在保持质量的同时大幅降低计算量
- **关键**: 线性注意力负责全局建模，残差连接保留局部细节 — 两全其美

### 3. LLMs Get Lost in Evolving User Intent
- **机构**: Microsoft Research | 👍 21
- **核心**: 发现 LLM 在多轮对话中用户意图动态变化时，模型会"迷失"方向，无法追踪意图的演化路径
- **意义**: 揭示了当前对齐技术的盲区 — 静态偏好优化无法应对动态意图

### 4. OO Agents: 原生 Python 面向对象 Agent
- **机构**: NVIDIA Labs | 👍 26
- **核心**: 将 AI Agent 建模为原生 Python 对象，无缝融入 Python 生态（类型检查、IDE 支持、调试工具）
- **亮点**: Agent 即 Class，Tool 即 Method，State 即 Attribute — 零学习成本

### 5. Show, Don't Tell: 生成像素评估空间认知
- **机构**: 浙大 OmniAI | 👍 35
- **核心**: 不靠文本问答，直接用生成图像来评估模型的空间理解能力
- **发现**: VLM 在文本上"会说"空间关系，但生成的像素"不会画" — 揭示文本-视觉的空间认知 gap
