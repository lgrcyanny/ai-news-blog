### 🔍 重点论文深度解析（3 篇）

#### 1. TUA-Bench — 通用终端 Agent 评测基准
- **核心问题**: Agent 评测集中在 GUI/Web，缺乏标准化 CLI/TUI Agent 基准
- **方法**: 构建多终端环境任务集，覆盖文件操作、系统管理、开发工具等 200+ 任务，统一评估协议
- **价值**: 推动终端 Agent 从 demo 走向可量化比较，加速 CLI Agent 研发

#### 2. Scaling the Horizon — 35B Agent 的万亿参数性能
- **核心问题**: 提升 Agent 能力是否必须扩大模型参数？
- **方法**: 扩展 Agent 的规划视野长度和推理深度，用搜索+验证代替参数堆叠，35B 达到千亿级效果
- **价值**: 为「小模型+强推理」的 Agent 架构提供有力证据，降低部署成本

#### 3. Agentic Abstention — Agent 的「不作为」智慧
- **核心问题**: 现有 Agent 总是被驱动去行动，但有时不行动才是最优选择
- **方法**: 构建需要主动弃权的任务集，提出 abstention-aware 评估指标，分析 GPT/Claude/Llama 各模型的弃权能力
- **价值**: 开辟 Agent 安全与效率的新研究维度——知道何时不行动与知道如何行动同样重要
