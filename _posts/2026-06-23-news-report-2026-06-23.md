### 🔍 重点论文深度解析（3 篇）

#### 1. GateMem — 多主体共享记忆 Agent 治理基准
- **核心问题**: 多个用户/主体共享一个 Agent 时，记忆访问控制、遗忘、冲突消解缺乏系统评估
- **方法**: 构建覆盖 6 大治理维度的基准，包括访问控制、遗忘权、优先级冲突等场景
- **价值**: 为 Agent 记忆安全与治理提供首个标准化评估框架，直接影响企业级 Agent 部署

#### 2. WorldLines — 长时域有状态具身 Agent 基准
- **核心问题**: 现有具身 Agent 评测只覆盖数秒至数分钟的操作，无法评估长时间跨度的状态保持
- **方法**: 构建跨多会话的状态演化基准，要求 Agent 在长时域中维护内部状态并做一致决策
- **价值**: 推动具身 Agent 从"单次操作"到"连续生活"的能力跃迁

#### 3. GeneralVLA-2 — 几何感知记忆的机器人规划
- **核心问题**: VLA 模型在复杂 3D 场景中缺乏几何理解，记忆模块与规划模块耦合不足
- **方法**: 几何感知 3D 重建 + 受控记忆读写机制，实现空间-记忆双通道驱动规划
- **价值**: 可部署级 VLA 架构升级，几何感知提升操作成功率，受控记忆降低灾难性遗忘
