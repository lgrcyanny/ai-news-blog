### 🔍 重点论文深度解析（≤ 3 篇，每篇 3-4 行）

#### 1. AgenticSTS — 长程 LLM Agent 有界记忆评测
- **核心问题**: 现有 Agent 评测忽略记忆容量约束，真实部署中上下文窗口有限
- **方法**: 构建有界记忆测试床，强制 Agent 在有限 token 预算下完成长程任务
- **价值**: 填补 Agent 记忆效率评测空白，推动从"无限记忆假设"到"实用约束"转变

#### 2. WorldDirector — 持久动态记忆驱动的可控世界模拟器
- **核心问题**: 现有世界模型缺乏持久记忆，场景切换后状态丢失
- **方法**: 引入持久动态记忆模块，支持跨场景状态保持与可控生成
- **价值**: 为 RL Agent 训练提供更真实的长期交互环境，少样本策略迁移的潜在方案

#### 3. SkillCoach — 自进化 Agent 技能评估
- **核心问题**: Agent 技能使用评估依赖人工设计评分标准，扩展性差
- **方法**: 自进化评分标准（rubrics），Agent 使用技能的反馈驱动评分标准自动更新
- **价值**: Agent 技能评估从静态人工标注走向动态自进化，规模化 Agent 训练的必备工具
