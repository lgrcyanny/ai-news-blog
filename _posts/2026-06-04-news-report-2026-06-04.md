### 🔍 重点论文深度解析（3 篇）

#### 1. OmniDreams — NVIDIA 实时生成式世界模型
- **核心问题**: 自动驾驶仿真需要同时满足实时性、物理精度和视觉质量，现有方案三者不可兼得
- **方法**: 提出实时生成式世界模型，在闭环仿真中同时生成高质量视觉场景和准确物理交互
- **价值**: 世界模型从「离线生成视频」走向「实时交互仿真」，自动驾驶训练范式可能被改写

#### 2. Small RL Controller, Large LM — RL 引导自适应采样
- **核心问题**: Test-time scaling 计算开销大，固定采样策略效率低
- **方法**: 训练小型 RL 控制器动态决定 LLM 何时停止采样、何时继续推理，自适应分配推理预算
- **价值**: RL × LLM 融合的新范式——不是让 LLM 做 RL，而是让 RL 为 LLM 的推理过程做调度

#### 3. The Meta-Agent Challenge — Agent 能否开发 Agent？
- **核心问题**: Agent 能力快速提升，但能否实现「用 Agent 开发 Agent」的自举闭环？
- **方法**: 构建系统化基准，评估当前 Agent 在 Agent 设计、实现、调试各环节的能力
- **价值**: 定义了 Agent 自举能力的评估标准——如果通过，意味着 AI 研发自动化进入新阶段
