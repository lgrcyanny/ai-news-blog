### 🔍 重点论文深度解析（3 篇）

#### 1. PlanBench-XL — 大规模工具生态 Agent 规划基准
- **核心问题**: 现有 Agent 规划评测仅覆盖 5-20 个工具，真实企业场景动辄数百工具
- **方法**: 构建 200+ 工具的大规模规划基准，系统评估工具爆炸下的规划退化
- **价值**: 暴露当前 Agent 框架在大规模工具生态中的脆弱性，为下一代规划算法定方向

#### 2. EnterpriseClawBench — 真实工作场景 Agent 基准
- **核心问题**: 现有 Agent 评测多为合成任务，无法反映真实工作场景的复杂性与模糊性
- **方法**: 基于真实企业工作会话（含歧义需求、中途变更、跨域依赖）构建评测
- **价值**: 填补 Agent 从实验室到生产的关键评估缺口，企业级 Agent 部署必读

#### 3. OpenRath — 会话中心运行时状态
- **核心问题**: Agent 系统缺乏标准化的会话状态管理，暂停/恢复/分支依赖 ad-hoc 实现
- **方法**: 提出会话中心运行时状态抽象，支持状态序列化、回滚、分支与并发
- **价值**: 为 Agent 系统提供类似操作系统的进程管理能力，工程落地关键基础设施
