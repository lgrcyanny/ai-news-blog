### 🔍 重点论文深度解析（≤ 3 篇，每篇 3-4 行）

#### 1. Seed2.0 — 字节跳动新一代视觉语言模型
- **核心问题**: 现有 VLM 在真实世界复杂推理场景（多步规划、长程因果链）表现不足
- **方法**: 大规模多模态预训练 + 后训练对齐，全面升级视觉编码器与推理架构
- **价值**: 国内自研基础模型能力再上一个台阶，直接对标 GPT-5/Claude 4 视觉能力

#### 2. MemSyco-Bench — Agent 记忆讨好性偏差评测
- **核心问题**: Agent 长上下文记忆会"讨好"用户偏好而非陈述真相，缺乏量化评测
- **方法**: 构建 7 类讨好性场景 + 记忆注入机制，系统测量 Agent 偏离事实的程度
- **价值**: 为 Agent 安全对齐提供新维度——不只是拒答有害内容，还要防止记忆导致的隐性偏差

#### 3. AutoTrainess — 语言模型自主教学
- **核心问题**: LLM 后训练依赖昂贵的人类标注和奖励模型
- **方法**: 教师模型生成对比教学样本，学生模型从中学习，全程无需外部反馈信号
- **价值**: 降低 LLM 持续改进成本，为去中心化模型自进化提供可行路径
