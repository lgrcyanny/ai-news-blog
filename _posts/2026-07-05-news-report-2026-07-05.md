### 🔍 重点论文深度解析（≤ 3 篇）

#### 1. Morphing — 混合注意力模型形态演化
- **核心问题**: Transformer 注意力机制固定不变，能否让模型自主学会切换稀疏/密集模式？
- **方法**: 训练时动态调整注意力模式，推理时根据输入自动选择最优混合架构
- **价值**: 可能打破"一个模型一个架构"的范式，模型本身成为可塑的计算形态

#### 2. DiscoBench — 搜索 Agent 何时该向用户提问
- **核心问题**: 搜索 Agent 遇到歧义时一搜到底，浪费 token 且可能跑偏
- **方法**: 构建澄清感知评测，让 Agent 学会判断何时该停下来向用户确认
- **价值**: 从"搜得多"转向"问得准"，实用 Agent 部署的关键痛点

#### 3. Learn to Move — VLA 先动后学的预训练范式
- **核心问题**: 视觉-语言-动作模型通常直接端到端学任务，基础运动能力薄弱
- **方法**: 先做任务无关的运动预训练（"学会动"），再叠加任务微调（"学会做"）
- **价值**: 提升 VLA 模型的鲁棒性和泛化能力，机器人基础模型的关键进步
