### 🔍 重点论文深度解析（3 篇）

#### 1. Cosmos 3 — NVIDIA 全模态物理世界模型
- **核心问题**: 机器人/自动驾驶需要世界模型同时处理视觉、物理、动作，现有方案模态割裂
- **方法**: 开源全模态架构，统一 tokenize 视频、物理状态、动作序列，支持理解+生成双模式
- **价值**: 物理 AI 的「GPT 时刻」——从专用仿真器走向通用世界模型开放平台

#### 2. Deep-Research Agent 错误定位 — Span 级轨迹分析
- **核心问题**: Agent 经常出错但不知道错在哪一步，粗粒度评测无法指导改进
- **方法**: 构建 span-level 错误标注框架，将 Agent 轨迹分解为搜索/推理/工具调用 span 并定位故障
- **价值**: Agent 可靠性工程的基础设施——从「错了」到「错在第三步的搜索 query 构造」

#### 3. Streaming Multi-Agent Communication — 流式多智能体推理
- **核心问题**: 多 Agent 协作时串行通信效率低，并行通信容易不一致
- **方法**: 提出流式通信协议，Agent 边推理边广播中间结果，实现 token 级实时协调
- **价值**: 多 Agent 系统从回合制走向实时协作，复杂推理任务效率有望数量级提升
