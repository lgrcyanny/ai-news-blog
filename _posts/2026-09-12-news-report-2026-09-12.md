### 🔍 深度分析（3 篇）

- **NCP-ArchPreview（2609.10715，157↑）**：从隐藏态直接构建乘积量化概念词表，用独立 Concept Module 预测"未来概念"并回灌 token 层，NTP 与 NCP 端到端联合训练；8.9B 参数在 Dolma-3 的 5.73T token 上训练。**分析：把"预测粒度"从 token 提升到 concept，是继 patch/vision tokenizer 之后对 LM 预训练目标本身最直接的一次改写——用 51.3% token 追平基线意味着同等算力下更省数据；17M VQ 模块即可做领域适配、注入 DFlash2 草稿器还能提速，说明潜空间可复用性强于单纯压缩。**
- **SenseNova-U1.5（2609.11929，126↑）**：编码器-free、VAE-free 的原生统一多模态，通过空间一致的 patch 重建强化视觉接口，原生分辨率至 4K；后训练用"多专家 on-policy 蒸馏"合并美学/双语文字渲染/信息图/编辑四类专家。**分析：商汤把"原生统一"路线推到 8B-MoT 并开源训练代码，直接对标闭源统一模型；"理解能力迁移到视觉规划与创造"是其主张的核心论点，值得关注其对结构化长指令的零样本泛化——若成立，统一建模将比"理解+外挂生成器"的组合更省工程。**
- **EvoSafeHarness（2609.05903，36↑）**：面向冻结模型，联合搜索自然语言策略与可执行代码逻辑，以模型行为 + 领域规格 + 新上下文对抗评审（拒绝 benchmark 专属规则）为指导合成可部署 harness。**分析：安全从"模型级"下沉到"系统级可合成层"，且强调 deployment-dependent——不同模型/域需要不同强度，避免"一刀切过阻塞"；AgentDojo 同点效用翻倍于 CaMeL、且不改动即可迁移到未见套件，说明 harness 有望成为 agent 部署的标准护栏。**

**其余看点**：世界模型簇——Recursive Code World Models（2609.11499，递归场景程序从单图重建 3D 世界）、World in World（2609.11548，免训练相机控制视频世界模型）、MaP-WAM（2609.11561，记忆即计划，RMBench 83.3%）；推理/蒸馏——Negative Self-Distillation（2609.11699，"远离错误推理"替代模仿特权解）、An Open Recipe for IMO Gold（2609.10712，Nemotron IMO 2026 30/42 金牌）、HyQuant（2608.27875，LLM attention 混合精度量化）、GLIE（2609.11808，生成式 late-interaction 检索压缩）；垂直——X-AuT（2609.11412，语音 LLM 音频编码器跨尺度蒸馏压缩）、TempCloze（2609.01515，视频 LLM 缺帧识别）、CARDEA（2609.06931，冠脉造影可审计推理）。
