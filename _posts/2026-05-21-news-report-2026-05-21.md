### 重点论文解读

#### 1. OpenComputer: Verifiable Software Worlds for Computer-Use Agents

- **来源**: arxiv.org/abs/2605.19769
- **核心贡献**: 首次为 Computer-Use Agent 引入**形式化可验证性**——Agent 在虚拟软件世界中的每次操作（点击、输入、导航）都有可验证的预期状态，而非仅凭"看起来正确"判断成功
- **方法**: 构建可验证软件世界（VSW）——在容器化环境中注入形式化规约，Agent 的操作被自动检查是否满足前置/后置条件。训练时用这些验证信号作为 RL reward，推理时 Agent 可以自我验证操作结果
- **价值**: 这是 Computer-Use Agent 从"能操作"到"操作可靠"的关键跨越。当前 Computer-Use Agent 的错误率仍然很高（点击错位置、导航到错误页面），可验证性意味着 Agent 可以自我纠错，朝「自主 Agent」迈出重要一步

#### 2. EnvFactory: Scaling Tool-Use Agents via Executable Environments Synthesis and Robust RL

- **来源**: arxiv.org/abs/2605.18703
- **核心贡献**: 解决 Agent 工具使用训练的数据瓶颈——不依赖人工构建环境和标注，而是**合成可执行环境**，在多样化合成环境中用 Robust RL 训练工具使用 Agent
- **方法**: EnvFactory 自动生成大量多样化的工具使用场景（API 调用、文件操作、数据库查询等），每个场景是一个可执行的微环境。用 Robust RL 在这些合成环境中训练 Agent，通过领域随机化（domain randomization）确保 Agent 在未见过的真实环境也能泛化
- **价值**: 工具使用是 Agent 的核心能力，但当前训练数据严重不足——人工构建工具使用场景成本极高。EnvFactory 的合成环境路线类似「用仿真训练机器人」，可能大幅加速 Agent 工具使用能力的进化

#### 3. GoLongRL: Capability-Oriented Long Context Reinforcement Learning with Multitask Alignment

- **来源**: arxiv.org/abs/2605.19577
- **核心贡献**: 重新定义长上下文 RL 的目标——不是让模型"能处理更长的输入"，而是让模型在长上下文中**保持各项能力不退化**（如数学推理、代码生成、翻译等）
- **方法**: 提出能力导向的长上下文 RL：在多任务混合环境中训练，reward 不仅看最终答案正确性，还衡量模型在不同上下文长度下的能力保持率。引入多任务对齐损失，防止长上下文训练损害短上下文性能
- **价值**: 当前长上下文模型普遍存在"越长越笨"的问题——上下文一长，数学/代码能力就下降。GoLongRL 直面这一根本矛盾，其能力保持导向可能成为长上下文训练的新标准
