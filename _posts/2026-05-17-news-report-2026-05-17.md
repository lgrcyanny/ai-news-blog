### 🌟 PapersWithCode Trending 论文精选

#### 1. TradingAgents: Multi-Agents LLM Financial Trading Framework

- **核心贡献**: 提出多智能体 LLM 金融交易框架——多个专业 Agent（分析师、交易员、风控官）协同完成市场分析到交易执行的全流程
- **关键方法**: 多角色 Agent 架构，每个 Agent 拥有独立记忆和分析视角，通过内部辩论机制达成交易决策共识。类似 AutoGen/crewAI 的多 Agent 模式，但针对金融交易场景做了深度定制
- **专业解读**: 这是 Agentic AI 在金融领域最系统化的尝试之一。之前的多 Agent 框架（如 ChatDev、AutoGen）侧重通用软件开发，TradingAgents 首次将「多角色辩论 + 交易决策」正式化。关键挑战在于：LLM 的市场预测能力本身存疑——如果底层模型无法 beat 市场，加再多 Agent 也只是 garbage-in-garbage-out。真正的价值可能在「风控 Agent」——用 LLM 理解非结构化风险信息（新闻、财报电话会），这恰恰是传统量化模型做不到的
- **对 Agentic RL 的启示**: 多 Agent 辩论机制本身可以看作一种无需人工反馈的偏好聚合方式——多个 Agent 对同一决策的投票相当于隐式的 reward signal

#### 2. Kronos: A Foundation Model for the Language of Financial Markets

- **核心贡献**: 将金融市场数据（价格序列、订单流、新闻）视为一种「语言」，构建金融领域的基础模型
- **关键方法**: 将限价订单簿（LOB）数据 tokenize 为序列，用类似 LLM 的自回归架构学习市场动态的通用表征，可微调到预测、风控、做市等多种下游任务
- **专业解读**: 这是「Foundation Model for X」思路在金融领域的应用。核心假设是：市场微观结构（订单流、价量关系）存在可迁移的通用模式，就像文本中的语法和语义。如果成立，Kronos 的价值类似于 GPT-2 之于 NLP——不是直接赚钱的工具，而是让后续所有金融 AI 应用站在更高的起点上。但风险同样明显：金融市场是非平稳的（regime change），「通用表征」可能在市场结构变化时失效
- **相关趋势**: AI-Trader（金融 Agent 实时基准测试）与 Kronos 形成互补——前者评估 Agent 表现，后者提供基础能力

#### 3. GenericAgent: A Token-Efficient Self-Evolving LLM Agent via Contextual Information Density Maximization (V1.0)

- **核心贡献**: 提出通过「上下文信息密度最大化」实现 token 高效的自我进化 Agent——让 Agent 在有限上下文窗口内自动优化提示和策略
- **关键方法**: 将 Agent 的上下文使用视为一个信息论优化问题——在固定 token 预算下最大化任务相关信息密度。Agent 通过自我反思自动压缩、重组、淘汰低效 prompt
- **专业解读**: 当前 Agent 的核心瓶颈之一是上下文窗口浪费——大量 token 花在重复的系统提示、格式规范、历史交互上。GenericAgent 的信息密度最大化思路直接针对这个问题。如果其自我进化机制能稳定收敛到更高效的 prompt 策略，对降低 Agent API 成本（token 消耗）有直接商业价值。但从方法论看，信息密度最大化本身也是 Agentic RL 的一个自然目标——可以形式化为 constrained MDP，reward = 任务完成质量 / token 消耗

#### 4. World Action Models: The Next Frontier in Embodied AI

- **核心贡献**: 提出「世界动作模型」概念——将世界模型（预测环境变化）与动作策略（决定做什么）统一在一个框架内，作为具身 AI 的下一前沿
- **关键方法**: 扩展 World Model 范式（如 Dreamer 系列），不仅预测未来观察，还直接输出动作——类似「内部模拟 + 决策」一体化
- **专业解读**: 世界模型一直是具身 AI 的核心方向（从 Ha & Schmidhuber 2018 到 Dreamer V3），但传统做法是「世界模型预测 → 策略网络决策」两步走。World Action Models 试图合并这两步，让模型在预测世界变化的同时就决定动作。如果成功，可以在计算效率（去掉独立的策略网络）和决策质量（更紧密的感知-行动耦合）上同时获益。但对于 Agentic RL，这也有风险——模型内部模拟的误差会直接传导到决策，可能导致「幻觉驱动的错误动作」

#### 5. SANA-Video: Efficient Video Generation with Block Linear Diffusion Transformer

- **核心贡献**: 用 Block Linear Diffusion Transformer 实现高效视频生成，在训练和推理效率上取得突破
- **专业解读**: 视频生成的效率瓶颈一直比图像生成严重得多——帧间注意力使计算复杂度 O(T²) 增长。SANA-Video 的 Block Linear 方法如果能在保持质量的前提下将复杂度降到 O(T)，对视频生成 Agent（如自动生成演示视频、仿真环境渲染）有直接价值
